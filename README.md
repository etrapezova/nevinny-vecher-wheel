# Невинный вечер

Музыкальное колесо для браузера ноутбука. Откройте `index.html` в Chrome или Edge. Для проверки сохранения истории запускайте с локального HTTP-сервера или через GitHub Pages.

Нажмите «Крутить колесо». После розыгрыша кнопка «Спели» исключает песню из текущего вечера. Можно вернуть последнюю спетую песню, сбросить историю или выключить звук. История хранится в браузере.

Под колесом видно, чьи песни уже выбрали и кто ещё ждёт. Через кнопку «Купить песню» ведущий может выбрать участника и одну из его оставшихся песен. Каждый участник получает один шуточный жетон на вечер. Покупка записывается в историю, а при сбросе вечера жетоны возвращаются.

В списке 147 песен. В карточке песни показаны реакции на сообщения, в которых её предложили. В общей статистике каждое сообщение считается один раз, даже если в нём предложили несколько песен.

Шанс выпадения зависит от числа людей, поставивших реакции. Если выгрузка содержит часть имён, число людей оценивается. После выпадения песни вероятность других песен того же автора временно снижается.

Примерно в трети вращений колесо сначала выбирает с равным шансом одного из тех, чьи песни ещё не выбирали и у кого остались песни. Затем оно выбирает одну из песен этого участника с учётом реакций. Если таких участников нет, колесо разыгрывает весь оставшийся список.

GitHub Pages публикует содержимое ветки `main` из корня репозитория.
